阶段一：潜藏与启动

☷
坤 · 手掌
地基 / 承载
你的知识储备、兴趣点与领域经验。这是你「可以做」的广阔平台，决定了你能产出什么内容。
☳
震 · 爆发
动力 / 启动
灵感迸发的那一刻，「我要拍了！」的冲动。决定视频是快速切入还是缓慢铺陈。
☰
乾 · 拇指
意志 / 发起
你的核心目标：为赚流量？传递理念？发泄情绪？这是整个视频的「决定」，影响一切后续选择。
🗺️
阶段二：探索与展现
坎 → 离 → 巽 · Execution & Manifestation
▼
☵
坎 · 食指
方向 / 引导
脚本的「问题意识」：你在解决什么问题？在引导观众思考什么？这是视频的核心驱动命题。
☲
离 · 中指
核心 / 显现
视频的「主角和信息点」。必须清晰、亮眼、聚焦——就是那个被点亮的、最闪耀的知识点或画面。
☴
巽 · 无名指
流动 / 连接
视频的「剪辑节奏」：如何从A点平顺过渡到B点？用转场、BGM、画面切换让信息流顺畅自然。
🛑
阶段三：收束与反馈
艮 → 兑 · Boundary & Feedback
▼
☶
艮 · 小指
边界 / 定点
结尾的「锚点」：一个强有力的总结句、画面定格或明确的CTA，让观众知道「到此为止，不要跑开」。
☱
兑 · 愉悦
反馈 / 喜悦
观众的「情绪反馈」：豁然开朗、开心大笑、赶紧点赞分享的交流欲望。这是整个循环的能量回收。

☰☳
乾 + 震
意志力 · 启动冲力
🔎 检查点：你的视频是否有强烈的「我要做」冲动？开篇 3 秒是否够炸？
⚡ 解决方案

增加开场 Hook 的力度（乾），用问题、冲突或反常识开场；使用快节奏画面切入（震），前 3 帧给到情绪冲击。
☵☲
坎 + 离
问题意识 · 核心显现
🔎 检查点：你在引导观众思考什么（坎）？你的核心信息是否足够闪亮（离）？
💡 解决方案

明确你的「一个主命题」（离）——整条视频只传递一件事；并设计一个核心提问句（坎）引发观众共鸣。
☴
巽
顺畅连接 · 流动
🔎 检查点：你的信息衔接是否自然？转场是否流畅？是否有突兀的「跳切」？
🌬️ 解决方案

避免生硬跳切，用 BGM 节奏点来触发转场；让视觉逻辑顺着「风」走——每个画面为下一个画面做铺垫。
☶
艮
稳定边界 · 定点
🔎 检查点：你的视频有没有一个强有力的「定格」？还是虚晃一枪就消失了？
🏔️ 解决方案

结尾不要只是「谢谢观看」——要是一个总结性金句 + 强画面定格，或一个明确的行动号召（关注 / 评论 / 收藏），让观众「停下来」。
☱
兑
体验反馈 · 喜悦
🔎 检查点：观众看完后感受是什么？是平静（艮）还是喜悦（兑）？有没有评论冲动？
💬 解决方案

在结尾抛出一个开放性问题（兑），邀请观众在评论区「交谈」；或制造「啊哈时刻」让观众产生豁然开朗的喜悦，激发分享欲。
